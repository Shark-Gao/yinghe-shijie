# 硬核视界 V1.1 工作流程

当前固定流程：

```text
1. ChatGPT 按项目选片原则与可选本地化包装思路推荐 YouTube 视频
2. 复制链接到 Telegram 下载原始 MP4
3. 导入剪映
4. 自动生成中英字幕
5. 按发布平台制作对应版本
6. 多平台发布，并记录各平台数据

## 多平台制作与发布

采用“一源多剪、多平台分发”。选片以国内受众与素材表现力为依据，不再由 B 站的推荐偏好决定全部选题和剪辑方式。

| 平台 | 内容角色 | 制作重点 |
|---|---|---|
| 抖音、快手 | 获取曝光与验证选题 | 优先 30–90 秒；前几秒给出冲突、结果或视觉奇观；节奏紧凑。 |
| 小红书 | 获取收藏、搜索与长尾流量 | 强化“冷知识 + 现实问题 + 可收藏”的标题和封面表达。 |
| B 站 | 系列化内容与品牌沉淀 | 可使用相对完整的版本；强化系列感、背景信息和观看价值。 |

同一源视频可以制作不同开头、时长、标题、封面和文案。中文包装始终优先突出冲突、结果、规模、成本、稀缺性或现实用途。

发布后记录播放、完播、互动、收藏/转发等数据，定期比较同一题材在各平台的表现，用数据调整后续选题与剪辑版本。
```

## 男性向选题与包装 V2

男性向不再只按“科技纪录片 / AI / 军事 / 冷知识”平铺选择，初期采用三条主线：

1. **地缘政治 / 国际局势（40%）**：用热点事件吸引进入，但必须落到地图、装备、能源、产业能力或现实结果。
2. **军事装备 / 战争机制（40%）**：优先战机、航母、潜艇、导弹防御、无人装备和战争机制。
3. **大国工程 / 科技 / 产业竞争（20%）**：芯片、GPU、AI、航天、港口、能源和超级机械。

每条视频先写一张选题卡：

```text
普通人问题：观众为什么要关心？
核心答案：这条视频最终要让观众明白什么？
前2秒钩子：第一句话和第一画面是什么？
5-10秒承诺：最晚什么时候交付核心答案？
情绪变化：观众看完后从什么判断变成什么判断？
系列归属：它属于哪个可连续更新的主题？
```

推荐、脚本和成片验收都必须通过这张选题卡。地缘政治内容还要核对事件时间、来源、事实与分析的边界；有争议的观点不能包装成已证实事实。

## 推荐前判断

推荐外网视频前，先按题材质量和素材表现力判断是否值得制作；如果有中国关联，再判断它能不能转成国内同类 UP 主常见的热门表达。中国关联不是淘汰没有关联候选的硬条件：

- 是否属于大国工程、产业竞争、AI 应用、军工装备、超级机械、地理冷知识、灾难复盘。
- 是否能提炼出明确标题钩子：冲突、规模、成本、稀缺性、现实用途、为什么很难。
- 是否有足够强的画面承载力：3D 动画、地图、工业现场、工程剖面、数据可视化。
- 是否能避免纯冷门原理感，让普通科技观众在标题阶段就知道为什么值得看。
- 如果存在中国关联，可以作为国内化包装和系列延展的加分项；没有中国关联时，不要为了凑关联而强行改写成敏感地缘政治题材。

## 当前原则

- 以原始视频和字幕为输入，优先产出 30—90 秒的独立答案型短视频。
- 可以使用中文旁白和 AI 辅助，但 AI 不替代选题角度、事实核查和最终口播判断。
- 同一源视频按平台调整开头、节奏、标题、封面和结尾，不直接全平台复制同一版。
- 优先连续测试 10 条，再根据数据决定是否扩展成长版或做成系列。
