# 硬核视界

「硬核视界」项目现在维护两个彼此独立的账号方向：男性向的「硬核视界」和女性向亲子育己的「TA成长笔记」。两者都以优质海外视频为视觉素材，面向抖音、快手、小红书、B 站等平台制作并分发适配版本。

## 推荐前的方向确认（强制）

以后说“推荐视频”“推荐一条”时，必须在请求中明确写出一个方向：

- `推荐男性向视频` / `推荐男性视频` / `推荐硬核视界视频`
- `推荐女性向视频` / `推荐女性视频` / `推荐 TA成长笔记视频`

如果没有方向，工作流会先询问“这次要推荐男性向（硬核视界）还是女性向（TA成长笔记）视频？”，不会先搜索、推荐或更新记录。两种方向不混用同一批记录。

## 每日自动任务

当前每日 1:00 的自动任务固定输出 6 条：男性向 3 条、女性向 3 条。两组分别查重、分别写入记录，并分别执行选题和封面流程；这个固定配额不需要再次询问方向。

## 账号定位

男性向「硬核视界」的核心定位是：**只讲军事武器及直接相关的武器系统、作战机制和技术细节**。面向希望看懂军事装备如何工作、如何作战以及受什么限制的中文观众，先让普通人看懂，再逐步建立专业度。

女性向测试账号「TA成长笔记」定位为：亲子育己、情绪管理、亲子沟通、家庭关系、女性自我成长。其选题、记录和复盘单独维护，详见 [`docs/ACCOUNT_PROFILES.md`](docs/ACCOUNT_PROFILES.md)。

核心方向：

- 视觉冲击强
- 信息密度高
- 少真人出镜或无真人出镜
- 适合中文二创解说
- 适合在抖音 / 快手 / 小红书 / Bilibili 等平台持续更新
- 一源多剪、多平台分发：按平台调整开头、节奏、时长、标题与封面

## 内容优先级

优先选择 YouTube 上画面质量高、靠视觉讲故事的视频：

- 3D 武器与装备动画
- 武器系统、装备剖面和作战机制拆解
- 军事地图动画（仅作为武器使用背景）
- 军工制造和武器维护过程
- 雷达、声呐、制导、防空反导和电子战演示
- 纪录片、战场复盘与数据可视化（核心必须落到具体武器）

## 本地化选题思路（可选加分项）

参考国内军事科普类 UP 主的常见选题，推荐外网源视频时判断它能不能转化成国内观众更熟悉的军事武器问题。中国关联和国内化表达是包装加分项，不是推荐硬门槛；优秀的外国武器、武器系统、战争机制和历史装备视频可以直接推荐。

- 武器平台：航母、潜艇、战斗机、轰炸机、坦克、火炮、装甲车和军用无人机。
- 武器系统：导弹、鱼雷、防空反导、雷达、声呐、制导、火控、电子战和弹药。
- 作战机制：武器如何发现、锁定、打击、拦截、突防、协同和补给维护。
- 军工场景：具体武器的研发、制造、测试、部署、升级和成本限制。
- 战争与地图：只有在解释具体武器的使用环境、射程、路线、部署或作战结果时使用。

选题不要停留在“某武器如何工作”，要尽量包装成一个国内观众能立刻理解的问题或冲突，例如：

- `导弹为什么能在高速飞行中锁定目标？`
- `航母内部如何保障舰载机连续起降？`
- `防空系统为什么仍然可能漏掉目标？`
- `潜艇如何在水下发现并攻击对手？`
- `无人机蜂群到底靠什么协同作战？`

## 男性向内容边界

男性向不再设置地缘政治、科技、AI、产业或普通工程的独立内容线，全部围绕具体军事武器或直接相关武器系统展开。

地图、国际局势、战争史和军工产业可以作为上下文，但必须回答一个具体的武器问题；不能只讲国家关系、热点立场、能源贸易或宏观产业竞争。

每条视频先完成四项：普通人问题、核心答案、前 2 秒钩子、看完后的情绪变化。标题、封面、前 5—10 秒口播和结尾必须围绕同一个问题。

## 追踪原则

- 可以重复推荐同一个 YouTube 频道。
- 不要重复推荐同一个源视频。
- 同一武器类别、同一系列或相近方向可以重复，只要源视频 URL 不同；优先做主题系列，不因方向重复而淘汰质量更高的新源片。
- 每次推荐、制作、发布后，及时更新对应记录文件。
