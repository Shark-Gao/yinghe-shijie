# 《公寓黑风暴》通用封面模板

本目录保存了三种尺寸的通用封面模板，统一使用用户提供的宣传海报作为底图，并且避开男主脸部和主体：

- `renders/apartment_job_template_16x9_横版.png`：1920×1080，适合横版视频和 B 站。
- `renders/apartment_job_template_4x3_标准版.png`：1600×1200，适合 4:3 发布位。
- `renders/apartment_job_template_3x4_竖版.png`：1080×1440，适合抖音、快手、小红书等竖版封面。

## 后续替换文案

修改 `cover_text.json` 中的字段即可：

- `series`：记录当前海报对应的剧名；剧名直接沿用海报上的原有字样，不再重复叠加。
- `episode`：集数，例如“第2集”，这是封面上新增的唯一集数信息。
- `segment`：本集中的故事段落，例如“第一段故事”，以小字显示在集数旁边。
- `topic`：本集讲什么，建议控制在一到两行。
- `tagline`：保留在配置中作为备注，不会叠加到封面，避免信息重复。

然后重新运行：

```powershell
python tools/make_apartment_job_covers.py
```

生成结果会更新到 `renders/`。当前示例文案是第一集：
“黑帮催债，竟然像财务审计”。

海报参考来源：用户提供的宣传海报；网上检索到的剧集资料可参考 [The Apartment Job 官方 Netflix 页面](https://www.netflix.com/title/82755552) 和 [JTBC 剧集海报资料页](https://www.sensacine.com/series/serie-1000003269/)。
