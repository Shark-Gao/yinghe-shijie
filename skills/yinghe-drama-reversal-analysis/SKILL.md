# 电视剧高能反转分析

把一集电视剧当成可重新组织的镜头库，找出能够脱离全集成立、前后认知发生变化、并且有清晰视觉证据的短视频候选。时间码和画面判断以本地视频为准，字幕用于定位对白，公开资料只用于补齐人物关系和核对剧情，不替代本地素材检查。

## 工作边界

- 用户只要求分析时，交付候选片段、剧情结构和剪辑建议，不创建 MP4、配音、封面或发布包装。
- 用户随后要求生成短视频时，转交项目内 `yinghe-short-video` 技能；不要在本技能中重复建立渲染流程。
- 项目内源视频和字幕优先；不得用网上的视频替代本地素材，也不得把网上剧情梗概误当成本地视频已出现的画面。
- 电视剧属于剧情内容，不自动套用军事向或女性向封面规则；只有进入制作流程且用户明确内容方向时再确定包装路线。

## 分析流程

### 1. 确认素材和时间基准

1. 定位本地视频与字幕文件，读取视频时长、分辨率、帧率和音视频轨道信息。
2. 读取字幕时间线，按场景合并相邻对白；记录片头、片尾、广告段、片尾字幕或字幕缺失区间。
3. 以视频时间码为最终时间基准，使用 `HH:MM:SS` 格式；不要只给字幕编号或模糊的“中段”“后半集”。
4. 检查字幕中的人名、称谓和 OCR 错字。无法确认时保留原文并标注“字幕疑似识别错误”，不要擅自改写剧情事实。

### 2. 建立反转链

对每个候选，至少标出以下节点中的三个；高优先级候选应尽量形成完整链条：

`铺垫/误导 → 危机或冲突 → 反转动作 → 他人认知改变 → 结果或余波`

优先寻找这些类型：

- 栽赃反制：原本要被问罪的人反而把责任推回幕后主使。
- 身份或证据揭示：一个细节改变所有人对事件的判断。
- 当场打脸：强势角色前一秒占上风，后一秒被迫道歉、受罚或降位。
- 危机化解：看似必败，主角用一个具体办法临场翻盘。
- 情绪反转：胆小、受压或被误解的人突然反击，获得行动或尊严。
- 事后识破：主角成功骗过现场所有人，但更高位角色在事后看出破绽。
- 喜剧反转：严肃命令、误会或威胁最后落到荒诞但有逻辑的结果。

不要把纯背景介绍、重复争吵、没有结果的暧昧对话或只有漂亮画面而没有认知变化的片段列为“高能反转”。这类内容可以单独标为“情绪/关系补充”。

### 3. 检查关键帧和画面可剪性

在字幕定位的候选前后抽取关键帧，至少检查：

- 是否有能在前 1–2 秒建立冲突的画面：突发动作、道具揭示、人物闯入、表情变化、现场混乱。
- 是否有反转证据画面：打开、拿出、冲出、跪下、转身、近景反应、处罚结果等。
- 是否有足够的正反打和反应镜头，能让观众看懂谁在说话、谁处于劣势。
- 横版画面裁成 9:16 后，主体是否仍然清楚；多人全景需要特别标注“竖屏会损失关系”。
- 画面下方是否已有中文字幕、台标、水印或其他文字；如果存在，提醒后期避免字幕重复和遮挡。
- 关键动作是否依赖原声、音效或音乐停顿；适合时在候选说明中标注“保留原声更好”。

视觉分析要服务于剪辑判断，不要只描述“画面好看”。明确说明画面如何证明反转、如何制造期待或如何完成结果。

### 4. 必要时参考公开资料

用户允许或本地字幕无法补齐人物关系时再浏览网络。优先使用正版平台分集简介、电视台页面、官方剧集页或可信剧情资料；至少用两个来源交叉核对关键情节。公开资料只做三件事：

1. 确认本集主线和人物关系。
2. 补充字幕缺失的前因后果。
3. 核对候选结尾是否真的完成反转。

最终回答中说明“本地素材为主、公开资料用于校准”，并在使用网上信息时给出链接。若网络资料和本地画面冲突，以本地视频可见内容为准，同时标注冲突。

### 5. 评分和排序

每个候选按 1–5 分评估，综合判断而不是机械相加：

| 维度 | 判断重点 |
|---|---|
| 反转强度 | 前后认知差是否明显，是否有“原来如此”或“竟然反过来” |
| 钩子强度 | 前 1–2 秒能否直接呈现冲突、结果或悬念 |
| 视觉证据 | 关键动作、道具、表情和现场反应是否看得清 |
| 独立成立 | 脱离全集后，观众能否理解人物、问题和结果 |
| 结果满足 | 是否有打脸、处罚、救下、揭穿、和解或情绪释放 |
| 剪辑可行 | 镜头衔接、对白完整度、竖屏裁切和原声条件是否足够 |

用 `S级/A级/B级` 排序：

- `S级`：反转清晰、画面有证据、结尾有结果，适合优先制作。
- `A级`：有明显剧情或情绪价值，但需要补充前因、压缩对白或跨段拼接。
- `B级`：适合作为补充、结尾笑点、人物关系或系列素材，不建议单独作为主推片段。

### 6. 设计剪辑候选

每条候选都要给出：

- 原始时间码和大致时长。
- 一句话剧情反转。
- 适合的开头钩子。
- 建议保留的关键对白或动作。
- 最佳结束卡点：结果落地、处罚宣布、角色反应或悬念停住。
- 画面优点与竖屏适配提醒。
- 是否需要跨段拼接、保留原声或补充背景信息。
- 适合的内容方向：爽感、悬疑、智斗、成长、情感、喜剧等。

优先推荐能够在一个片段内完成“问题—反转—结果”的候选。若原始段落过长，指出应删掉的铺垫和可保留的结果，不要为了凑 30–90 秒而删掉必要证据；如果完整反转需要更长时间，应明确说明。

## 推荐输出格式

先给结论，再给排序表。表格建议使用以下字段：

| 优先级 | 时间码 | 反转类型 | 剧情核心 | 开头钩子 | 结尾卡点 | 画面与剪辑价值 |
|---|---|---|---|---|---|---|

表格后补充三部分：

1. **首选方案**：只选一条时，说明为什么选它，以及建议的剪辑顺序。
2. **画面分析**：说明分辨率、构图、特写、色彩、动作、原字幕/水印和竖屏适配问题。
3. **素材注意事项**：字幕 OCR 错字、缺失字幕、片尾时间、需要保留原声的节点，以及网络资料和本地视频是否一致。

如果用户没有要求标题和简介，不要擅自生成完整发布包装；可以提供一条简短的选题方向或标题示例帮助判断，但不要把它当作制作交付物。

## 质量检查

交付前确认：

- 每条时间码都能在本地视频中找到对应画面和对白。
- 每条候选都有明确的反转动作或认知变化，不只是剧情概括。
- 开头钩子不提前泄露全部结果，结尾卡点能完成释放或留下有效悬念。
- 公开资料和本地视频的作用已区分，引用的网络信息有来源链接。
- 已说明原字幕、水印、横转竖、对白完整度等实际剪辑风险。
- 没有把演员表、片尾字幕或无剧情片段误列为高能候选。
