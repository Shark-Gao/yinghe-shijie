# 发布后数据复盘规范

## 复盘目的

不要只用播放量判断视频好坏。每条视频至少拆成四个维度：

1. **播放规模**：平台愿意把视频分发给多少人。
2. **观看效率**：观众点进来后是否继续看、看完和重复观看。
3. **互动效率**：观众是否点赞、评论、转发或收藏。
4. **转化效率**：是否带来关注、主页访问或系列观看。

银针视频属于播放规模更强的样本；绣线视频虽然播放量较低，但平均播放时长相对片长不差。复盘时必须把“绝对量”和“相对效率”分开。

## 当前项目的已验证迭代经验

本节是根据已发布电视剧剧情样本沉淀的可复用假设。使用时仍要结合新作品的平台、时长、版本和统计时间，不把单条样本直接当作普遍规律。

- **播放规模先看增长阶段**：发布后约12—18小时出现单小时播放突增，可记录为平台二次分发信号。23—24小时适合做阶段性判断，但应继续保留后续统计时间点，避免把短时爆发当成最终表现。
- **观看指标要联合判断**：当2秒跳出率高于同类、平均播放时长高于同类、完播率却略低时，不要只归因于“开头差”或“视频太长”。这更像开头和尾段的两头损失：一部分观众没有进入故事，留下的人能看得更深，但仍有人在结果释放前离开。
- **受众匹配可以支持系列化**：女性占比、核心年龄段和重度活跃用户占比均与剧情定位相符时，优先继续同一人物或同一类冲突，不要因为互动短板立即换赛道。
- **点赞强、评论分享弱的含义**：观众已经有情绪认同，但内容没有把认同转成讨论或转发理由。结尾应先给出素材已经展示的结果，再补一条明确的原创判断和一个具体问题，例如“你觉得关键是道具，还是人物当时的处理方式？”或“如果她当时失态，结果还会改变吗？”

### 下一条测试规则

一次复盘最多确定1—2个变量。对上述“两头损失”样本，建议保持题材、人物、封面主承诺、故事链和大致时长不变，只测试：

1. **前2秒钩子**：直接说出人物、冲突和结果诱因，例如“她刚被撂牌子，皇帝却因为一朵花改口”。
2. **结果后的互动落点**：不提前打断结果，先让观众看到阶段性结局，再用“我的判断是……”加一个反事实或二选一问题收尾。

如果下一条同时改了标题、封面、时长、镜头链和结尾，就不能判断数据变化来自哪一项。

## 两条视频的对照方法

横向比较前先确认：平台相同、账号相同、统计时间相近、视频时长和版本明确。然后分别看：

- 播放量和播放增长速度：判断分发规模。
- 完播率和2/5/10秒留存：判断开头与故事完成度。
- 平均观看时长 ÷ 视频时长：判断单位观看深度。
- 评论、分享、收藏 ÷ 播放量：判断互动效率，不只看互动绝对数量。
- 关注 ÷ 播放量：判断选题和包装是否带来账号转化。

不要因为视频更短就直接认定它一定更好，也不要因为播放量更高就认定内容逻辑更强。

## 复盘结论模板

```text
本条视频类型：播放规模型 / 观看效率型 / 互动讨论型 / 转化型
最强环节：选题 / 道具 / 开头 / 封面 / 标题 / 证据链 / 结果 / 注释
主要损失点：前2秒 / 前10秒 / 中段解释 / 结尾 / 包装 / 平台适配
已验证经验：下一条继续保留什么
待测试变量：下一条只改变什么
下一步动作：选题、标题、封面、时长、注释密度或版本选择
```

一次复盘最多确定1—2个下一步变量，避免同时改变标题、封面、时长和剪辑后无法判断原因。
