# 故事选择与原创剪辑规范

## 剧情卡

制作前填写：

```text
本条核心冲突：谁为了什么，陷入什么困境
普通观众问题：观众看完要知道什么
具体道具/异常：什么物件、动作或细节让冲突立刻可见
开头立场钩子：前2秒出现的冲突判断或尖锐问题
前5秒危险：如果不看下去，观众会错过什么代价或反转
解说立场/观点：基于素材事实，对选择、责任、边界或代价的判断
可讨论的冲突点：观众可以从不同角度讨论的具体问题
观众情绪价值：看完后的爽感、释然、震惊、同情或认知变化
观众最早应知道的结果：反转、代价或关键选择
结尾阶段性结果：素材明确展示的处罚、奖励、揭穿、救下或暂时稳定
人物关系：身份、与主角的关系、当前利益冲突
起因 → 升级 → 转折 → 当集落点：各一句
不能断言的内容：未由素材、字幕或授权资料证实的动机和后续
```

如果只能复述集数进度，或无法写出明确的人性问题、具体道具和阶段性结果，应换选冲突更完整的素材。

## 双评分与优先级

### 内容完成度

每项1—5分，判断观众脱离全集后能否看懂和获得结果：

| 维度 | 判断重点 |
|---|---|
| 反转强度 | 前后认知是否明显改变，是否有“原来如此” |
| 独立成立 | 人物、问题、因果和结果能否在本条内成立 |
| 因果清楚 | 主角为什么这样做，做完造成什么变化 |
| 视觉证据 | 道具、动作、表情和反应能否证明观点 |
| 结果满足 | 是否有处罚、奖励、揭穿、救下或有效悬念 |
| 剪辑可行 | 对白边界、镜头衔接、竖屏裁切和原声条件 |

### 分发潜力

每项1—5分，判断观众为什么会点进来：

| 维度 | 判断重点 |
|---|---|
| 道具记忆点 | 道具或异常是否一眼能说清，能否成为标题主语 |
| 冲突即时性 | 前2秒是否有危险、指责、证据或人物反应 |
| 结果诱因 | 标题和封面是否能承诺恶果、奖励、翻盘或揭穿 |
| 人物责任 | 是否能快速理解“谁可能倒霉、谁掌握判断权” |
| 缩略图可读 | 画面缩小后主体、标题和冲突是否仍然清楚 |
| 情绪普适性 | 观众是否不熟悉全集也能理解并产生情绪 |

优先级不机械相加：

- **S级**：两项都高，既有强点击理由，又能在一条片内完成冲突和结果。
- **A级**：内容完成度高，但分发潜力或画面证据较弱，需要加强标题、开头或包装。
- **B级**：只有漂亮画面、背景信息、重复争吵或没有结果的暧昧对话，适合作为补充素材。

## 单冲突和故事链

默认只讲一条独立冲突链，不把“救人”“翻案”等独立支线硬塞在同一条短视频里。优先按：

> 具体异常 → 危机/惩罚 → 追问或阻碍 → 主角改局 → 他人认知改变 → 阶段性结果

组织内容。高能不等于镜头越多，而是观众的判断发生了变化。

## 三段式开头

- **0—2秒：看见异常**。使用道具近景、突发动作、人物反应、证据揭示或直接冲突，不从剧名和背景介绍开始。
- **2—5秒：知道危险**。说明这不是普通小事，而是可能被问罪、被揭穿、失去机会或改变关系。
- **5—10秒：知道看点**。交付主问题，例如“她要怎么把犯错解释成守规矩”，但不要提前说出所有结果。

开头画面、第一条口播/注释和封面主标题必须指向同一件事。若标题讲银针，开头就不能先讲无关人物背景；若封面讲绣线追责，前10秒就必须让观众知道追责的危险。

## 时长档位

时长由证据链决定，不为了凑30—90秒删除必要证据：

- 单次判断翻盘：通常90—130秒。
- 多阶段悬疑、证据揭示或连续反制：通常150—210秒。
- 30—90秒只适合本身已有完整问题—反转—结果的短段，不是所有电视剧素材的硬上限。

结尾必须保留结果落地、人物反应或有效悬念的画面，不用硬切结尾换取短时长。

## 原创表达与证据片段

- 原创解说负责交代身份、因果、证据、选择代价、观点和情绪落点；不要逐句把对白换成旁白。
- 每个源片段都要写清“它证明了哪一个观点”；不能证明就删除，或改用分析卡、时间线、道具/场景信息图和其他有依据的原创视觉。
- 能用一个动作、反应、视线或道具证明时，不保留整段对话；但关键动作必须保留起势、执行、反应和紧接着的后果。
- 原剧原声采用必要引用原则，只保留关键事实、人物态度、动作结果和必要环境声；其他原声压低或删除。
- 原创视觉不能生成可识别演员脸、伪造剧照、官方 Logo 或会被误认为原剧的画面。

## 文案事实层级

按“事实 → 分析 → 讨论”组织：事实来自画面、字幕、对白和动作；分析是根据行为和后果得出的判断；讨论保留开放性。不得把未说出口的心理、动机、后续命运或全局评价写成剧情事实。

旁白保持冷静拆局、口语易懂；删除“这波属于”“马上见分晓”“高能来了”等填充句。结尾先交付结果，再给观点和具体讨论问题，不能只说“下一集见”。
